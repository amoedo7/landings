# DesarrollAMO · Public positioning rules

Este documento define qué puede mostrarse públicamente en piezas orientadas a clientes.

## Objetivo

La presencia pública de DesarrollAMO debe transmitir capacidad, continuidad y profesionalismo mediante **evidencia visible**, no mediante detalles internos ni afirmaciones difíciles de respaldar.

## Reglas

1. **Cliente primero.** Explicar qué problema se resuelve y qué puede recibir el cliente.
2. **Prueba antes que promesa.** Priorizar demos ejecutables, productos desplegados, capturas verificables, código y resultados.
3. **No publicar una oficina como capacidad consolidada si no existe respaldo funcional suficiente.** Una capacidad en desarrollo puede describirse como parte del método sin presentarla como unidad consolidada.
4. **No exponer conversaciones internas, prompts, proveedores, consumo de tokens, arquitectura privada o decisiones de operación que no aporten confianza comercial.**
5. **No afirmar tamaño de equipo, cantidad de empleados ni estructura humana que no esté documentada públicamente.** La marca puede hablar como organización sin publicar headcount.
6. **No convertir prototipos históricos en productos actuales.** Si se muestran, deben etiquetarse por lo que realmente son.
7. **Favorecer soluciones multiplataforma.** Cuando tenga sentido, demostrar el mismo resultado en Android/Termux, Linux/macOS, Windows o Python mediante un contrato de salida común.
8. **Todo CTA debe llevar a una acción real:** abrir demo, ver código, probar producto, contactar o solicitar propuesta.
9. **La estética acompaña a la evidencia.** Ningún gráfico, oficina o concepto visual debe sustituir una implementación funcional.
10. **Mantener neutral la estructura humana.** No hace falta explicar públicamente cuántas personas trabajan detrás de DesarrollAMO; tampoco inventarlo.

## Criterio de publicación

Una pieza nueva debería cumplir al menos uno de estos puntos:

- demo ejecutable;
- producto desplegado;
- código reutilizable;
- caso real documentado sin exponer información sensible;
- comparación antes/después medible;
- herramienta que resuelve una tarea concreta.

Si no cumple ninguno, puede permanecer como concepto interno hasta tener respaldo.
